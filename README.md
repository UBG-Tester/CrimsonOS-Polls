# Crimson OS Preferences

**Your opinions shape the experience.** A dark crimson community poll website with live results and a password-protected admin dashboard.

## Features
- Community polls about the 2016–2018 vs. 2020–2024 eras, aesthetics, graphics, atmosphere, and future direction.
- One submission can answer any number of questions; questions can be skipped.
- Optional usernames, anonymous submissions, and written comments.
- Live result bars, refreshing every 15 seconds.
- Admin dashboard at `/admin`: inspect submissions by username, see every answer and comment, filter, and delete a submission.
- Express API, basic rate limits, session-protected admin routes, health check at `/health`.

## Render deployment
This repository includes `render.yaml` for a Render Blueprint. The service uses Node.js, `npm install`, `npm start`, and a persistent disk mounted at `/var/data` for vote storage. Set a strong `ADMIN_PASSWORD` (at least 12 characters) when prompted. `SESSION_SECRET` is generated by the Blueprint.

**Data note:** Votes are stored in a JSON file on the persistent disk. This is intentionally a small, single-instance community poll app, not a high-volume voting platform. Keep admin credentials private.
